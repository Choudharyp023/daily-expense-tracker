# Daily Expense Tracker

A simple Python console application built while learning python fundamentals.

## Features

✅ Add expenses

✅ View all expenses

✅ Calculate total expenses

✅ Calculate average expenses

✅ Clear all expenses

✅ Exit application

## Concepts Used

- Lists
- While Loops
- Conditional Statements
- User Input
- Enumerate Function
- Basic Calculations

## How To Run

1. Download the project
2. Open terminal
3. Run

python daily_expense_tracker.py
